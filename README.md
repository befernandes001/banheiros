Como abrir: dê dois cliques em index.html, ou arraste o arquivo para o Chrome, Edge ou Firefox.
Se a localização não funcionar no arquivo direto, nesta pasta rode: python3 -m http.server 8765
Acesse http://127.0.0.1:8765 no computador ou no celular, na mesma rede.
Permita a localização, ou digite uma cidade ou endereço e toque em Buscar.
Os pontos são só banheiros públicos devolvidos pelo OpenStreetMap; a cobertura no Brasil é incompleta.
